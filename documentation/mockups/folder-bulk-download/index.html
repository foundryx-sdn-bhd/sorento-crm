Lifecycle: row created pending when Download selected is clicked (same request that starts the job); processing when the worker starts; ready with the storage key when the archive is uploaded; failed with the one-line reason otherwise. The dialog and the drawer read the same row, so the dialog's Download ZIP and the drawer's Download open the same 1-hour link. Removal after 24 h is the existing daily purge with a 24 h window for this kind (every other kind keeps its 30 days).
