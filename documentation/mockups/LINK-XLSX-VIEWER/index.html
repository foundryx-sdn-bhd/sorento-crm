Short-link Excel viewer (mockup v2)

Page /f/<code> for a "sheet" link. Today: filename + View/Download buttons and the small AttachmentPreviewModal table (200 rows x 40 cols, text only, cells cut at 240px). Proposed: the sheet IS the page, full screen, rendered from the file's own column widths, number formats, bold, merges and frozen panes. Data: same structure as the real supplier packing list the owner screenshotted (one sheet PL, A1:M24, header block rows 1-4, bold header row 7, 16 lines, bold SUM TOTAL row, #,##0.00 formats); every code, figure and the container number are INVENTED (public repo, owner Q5).

1Opened on phone (375) and desktop (1280)

Opens straight into the sheet (no extra "View" tap). Excel-style column letters stay pinned on top and row numbers on the left. The file declares no freeze pane, so here the viewer pins the table's header row (row 7, the first all-bold row) under the letters (owner Q2: the file's freeze pane when set, else the first all-bold row, else letters + row numbers only). Numbers keep the file's format (#,##0.00), formulas show the value Excel last saved (TOTAL row), never recalculated. Swipe scrolls both ways; pinch zooms the grid only.

1280 x 720. All 13 columns fit; rows 21-24 one scroll down; DESCRIPTION shows at the file's own width (27.9 chars), nothing cut.

2Search, and a workbook with more than one sheet

Search marks every matching cell and jumps to the first; up/down arrows step through matches. Rows stay in place (no filtering), so the sheet still reads as the file. Sheet tabs sit at the bottom like Excel and scroll sideways when there are many.

Search "basin": 6 cells, 2 of 6 selected. Second sheet tab "Summary" (illustrative; this file has one sheet).
