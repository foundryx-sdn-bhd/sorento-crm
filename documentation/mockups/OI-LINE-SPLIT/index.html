Split delivery: one sheet, splits stacked under their line (OI-LINE-SPLIT, mockup v3)

v3 after the owner's hand test of PR #1749 (17 Oct ~12:40, FAIL): "supposed to be 1 page only view all products, and refer to the excel, when i split i can split vertically not horizontally". One full-screen page, one table with every line of the SO, columns as the staff's ORDER INQUIRY Excel. A split stacks DOWNWARD inside its line: the line's own cells (SO date to delivery date) are merged across its split rows, each split row has its own change quantity, change date and remark. A line that is not split reads REMAIN. No date columns, no cards, no side panel, no second step. Everything below is live: type in it.

1The sheet (live)

Opened from a line's "Split delivery…" (board row menu, or the AutoCount change lightbox inside Confirm): the whole SO opens and that line is scrolled to and flashed (here CSK14B line 480). Click REMAIN or type a quantity to split a line; "+ Split" adds a row under the line filled with what is left; × removes a row. BALANCE = line qty minus the split rows; Save waits until every line is 0 (owner ruling Q2 b, unchanged). The case is the owner's Excel: CSK14B 417 @ 20/10/2026 split 14 / 236 / 167 and 504 @ 20/12/2026 split 37 / 467.

4Keyboard

Excel habits. Listed in the Outline guide, not on screen.

WhereKeys
Any cellTab / Shift+Tab next / previous cell · Enter or ↓ the same column one row down · Shift+Enter or ↑ one row up
REMAIN celltype a number or a date: the line splits and the row takes it
Change quantity / change dateCtrl/Cmd+Enter add a split row under this line (filled with what is left) · Ctrl/Cmd+Backspace remove this split row · dates type as d/m/yyyy (20/9/2026), or pick from the calendar
AnywhereCtrl/Cmd+Z undo the last change · Esc closes a calendar or list

6Questions (also in the crew ask)

Q1 Drag and drop. (a) None: type like the Excel, "+ Split" and × for rows. (b) Also a grip on a split row to drag it onto another line of the same item, which sets its AutoCount line. Recommend (a): the hand test said the drag screen was too hard and the Excel has none; the AutoCount line is one pick from a list (Q2).
Q2 AUTOCOUNT LINE column (which AutoCount line carries the split, so Confirm moves its reservations there; staff-picked only, ruling Q3 a). (a) A visible column, "New line" until AutoCount has it, "Cancel" in the same list. (b) Hidden in a row menu. Recommend (a): a hidden link gets missed and Confirm then tells purchasing to order and cancel the same qty.
Q3 A new split row starts with (a) what is left on the line (417: type 14, "+ Split" gives 403, type 236, "+ Split" gives 167) or (b) 0. Recommend (a): three keystrokes per split, balance reaches 0 by itself.
Q4 SO DATE and S/O NO columns repeat on every row as in the Excel. (a) Keep them on desktop (merged per line), drop them on the phone. (b) Drop them (the title already names the SO). Recommend (a): the owner asked for the Excel's look.
