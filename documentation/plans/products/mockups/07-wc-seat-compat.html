What changed from v1

  • One plain table of the 49 flyer pairs (Row, Model, Seat cover, SKU count, Status) with a tick per row. Ticking a pair links all its ready SKUs. The SKU list sits behind the row's expand arrow.
  • Three tabs instead of the summary line: To link, Linked, Unresolved. Unresolved lists SKUs with the reason in one column. Nothing in it can be ticked.
  • Retire Seat Cover spec moved to the page header actions. It stays disabled until the flyer is linked and runs the usual 10s countdown.
  • No callout badges, no per-model cards, no extra code-part chips, no sticky bar (the list toolbar's selection strip does that job).

Built only from existing components

  • Page shell and title: components/common/container.tsx, components/common/PageHeader.tsx (its actions slot holds Retire), as on master-data-management/flyer-spec-proposals/page.tsx.
  • Tabs: components/ui/tabs.tsx with TabsList variant="line", as in sales/teams/[id]/components/SalesTeamDetail.tsx:339.
  • List: components/ui/data-grid.tsx + data-grid-table.tsx in components/ui/card.tsx (Card / CardHeader / CardTable), toolbar components/ui/data-grid-list-toolbar.tsx with its bulk strip, tick column components/ui/data-grid-select-column.tsx, search components/common/ListSearchInput.tsx: the same stack as Spec registry, master-data-management/product-specifications/components/SpecRegistryGrid.tsx:301-372.
  • Row expand: the DataGrid column meta.expandedContent (components/ui/data-grid.tsx:21), as in scm/components/ProductPerspectiveGrid.tsx:163.
  • Status: components/ui/badge.tsx. Retire countdown: hooks/useDeferredRowAction.tsx.
  • Product page section: unchanged; the same row and empty-state markup as products/[id]/components/ProductAlternativesSection.tsx, with ProductVariantPickerDialog.tsx for Add.
  • At 375px the table scrolls sideways inside its own card, the DataGrid's built-in scroller (components/ui/data-grid-table.tsx DataGridScroller), as every other list does; the page never scrolls sideways.
