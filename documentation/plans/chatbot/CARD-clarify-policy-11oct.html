The earlier subject never expires by time.

What changes for a contact

  • Loop breaker: the same question at most twice in a row. Third time: "I still need the attachment type for CB1512ASS." plus the handover offer (or "Please refer to your salesman." when handover is off). Never a guess.
  • Topic menus: replaced by an answer for the named thing plus "Something else? Tell me what you need about X."
  • Earlier subject, unclear: the questions above, before anything is fetched. The user answers 1 / 2 or in their own words. "Delivery for this" uses the earlier subject with no question.
  • Everything else stays exactly as today until you switch a row.

The settings table (one row per question)

Each row: the question in plain words, what the bot does (ask / default / collapse), which choices are possible, what "default" means, and how many times it may repeat (2). Only rows where the other behaviour already exists can be switched now:

  • Delivery order period, sales order period: ask (today) or default = newest 20, no date window.
  • Outstanding SO / DO / both: ask (today) or default = both.
  • Earlier subject + new subject: ask (your rule), carry (today), or drop.
  • Earlier subject, no reference: ask (your Q9), carry (today), or drop.
  • Topic menu: answer the named thing (your Q5) or menu.

Edge cases

  • A row can only be set to a choice the bot supports; anything else is refused.
  • If the settings cannot be read, the bot uses the starting settings, never "no question".
  • The earlier-subject question is not asked when the user repeats the earlier thing, answers a pending question, or names a new thing of the same kind (a new customer replaces the old one, as today).
  • A default never widens what a contact may see.
