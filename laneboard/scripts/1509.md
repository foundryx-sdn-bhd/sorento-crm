## Setup

   General Enquiries access (the console's default test contact 900000008 is fine). Send
   `cancel` first if a picker or task is open.
2. Confirm on the copy's database that `brands` holds active rows named `Cabana` and
   `Sorento` (`SELECT brand_code, brand_name FROM brands WHERE is_active;`), that promotions
   whose description contains "basin" exist (`SELECT count(*) FROM promotions WHERE
   description ILIKE '%basin%';` was 31 on dev) and that at least one product in the Wash
   Basin class carries a 1 mm thickness spec (`SELECT count(*) FROM product_specifications
   WHERE values->'class'->>'value' = 'Wash Basin' AND values->'thickness'->>'value' = '1';`).
   If the thickness count is 0, step 1 below ends on the zero-set line instead of rows.
3. Keep the console trace open: each step names the parse-stage entities to confirm the
   parser read the sentence the way the rule expects. A step whose parse differs is a
   parser finding, not this lane's.
