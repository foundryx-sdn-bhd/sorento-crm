Prod 5 Oct 2026 12:02: "m495 techincal drawings" got a product list instead of the technical
drawing files. The typo'd document word is now kept when the parser read it as a document type
and one typed word is a word of that type ("drawing"). A misspelt word is still never put right
on its own: a descriptor the parser misfiled as a document type is still dropped.

6. Start a new conversation and send "any pink colour water closet?".
