# Hand test #1479 (CHAT-PRODUCT-LABELS)

## URL
crew test copy

## Setup

1. Sign in as an admin who can open System Management > Chatbot Console and System Management > Translations.
2. Use any contact allowed to ask about product information. SRTWC286 must exist on the test copy (any product code with a description works; swap it in below).
3. Before step 1, open the Translations page, filter target language Malay, and search `List Price`. Note whether a row exists (on a fresh copy it does not).

## Steps

1. From the sidebar open System > Messaging > Chatbot Console and pick the contact.
2. Send `Boleh saya dapat maklumat produk SRTWC286?` and read the reply.
3. Send `SRTWC286 的产品资料` and read the reply.
4. Send `Boleh saya dapat fail lampiran produk SRTWC286?` and read the reply.
5. Send `product info SRTWC286` and read the reply.
6. From the sidebar open System Management > Translations, filter target language Malay and search `List Price`.
7. Edit the Malay `List Price` row to `Harga Katalog` and save.
8. Back in the Chatbot Console, send `Boleh saya dapat maklumat produk SRTWC286?` again.
9. In Translations, filter target language Chinese and search `Dimensions`.

## Expected

1. The console opens with the contact selected.
2. The reply opens with `Berikut ialah produk yang sepadan.` and its labels read `*Syarikat:*`, `*Kod Produk:*`, `*Keterangan:*`, `*Harga Senarai:*`, `*Dimensi:*` and `*Spesifikasi:*`. A missing price or size reads `Tidak ditetapkan`. The description text, product name and the spec names inside Spesifikasi (Width, Height and so on) stay exactly as stored, in English.
3. The reply opens with `以下是匹配的产品。` and its labels read `*公司:*`, `*产品代码:*`, `*描述:*`, `*标价:*`, `*尺寸:*` and `*规格:*`. A missing price or size reads `未设定`.
4. A product file reply opens with `Berikut ialah fail produk yang saya temui.` and its labels read `*Jenis Lampiran:*`, `*Nama Fail:*`, `*No. Sijil:*`, `*Sah Sehingga:*`, `*Kesahan:*` and `*Pautan Fail:*` where the file has them. The validity value reads `Sah` (valid), `Akan tamat tempoh`, `Tamat tempoh`, `Belum sah` or `Tidak diketahui`, and a file with no link reads `(pautan fail tidak tersedia buat masa ini)`. The attachment type name and the file name stay as stored.
5. The English reply is unchanged from before this PR: `Here are the matching products.`, `*Description:*`, `*List Price:*`, `*Dimensions:*`, `*Specs:*`.
6. A `List Price` row exists for Malay with `Harga Senarai`, source AI, created by step 2.
7. The row saves and shows as manual.
8. The price line now reads `*Harga Katalog:*`. Every other label is as in step 2.
9. A `Dimensions` row exists for Chinese with `尺寸`, created by step 3.
