crew test copy

## Setup

Crew setup on the dev DB, before handing over. The owner runs no commands.

1. Apply the `crew-migration` SQL from PR #1569 (the rkind_0002 parser prompt version). It inserts one
   unlabelled `chatbot_semantic_parser` version with commit message starting
   `rkind_0002_parser_ref_kinds_v56:`. Note its version number as `<V>`. No label moves.
2. Pick the values below with read-only SELECTs on the dev DB and write them into this script:
   - `<DO>`: a recent delivery order number that is no SO, PO or PR number:
     `SELECT o.order_number FROM orders o WHERE NOT EXISTS (SELECT 1 FROM sales_orders s WHERE lower(s.so_number) = lower(o.order_number)) AND NOT EXISTS (SELECT 1 FROM purchase_orders p WHERE lower(p.po_number) = lower(o.order_number)) ORDER BY o.created_at DESC LIMIT 1;`
   - `<SO>` and `<SO_CUST>`: a dashed sales order of the DEALER's linked customer (step 3), plus its debtor name:
     `SELECT so_number, debtor_name FROM sales_orders WHERE so_number LIKE '%-%' AND customer_id = '<DEALER customer id>' ORDER BY order_date DESC NULLS LAST LIMIT 1;`
   - `<SO_OTHER>`: a dashed sales order of a DIFFERENT customer: same query with `customer_id <> '<DEALER customer id>'`.
   - `<PO>`, `<SUPPLIER>`, `<PO_STATUS>`, `<PO_DAY>`: a purchase order with an issue date, plus its supplier name, status and issue date written `d Mon yyyy`:
     `SELECT p.po_number, s.supplier_name, p.status, p.issue_date FROM purchase_orders p LEFT JOIN suppliers s ON s.id = p.supplier_id WHERE p.issue_date IS NOT NULL ORDER BY p.issue_date DESC LIMIT 1;`
   - `<PR>`: `SELECT request_number FROM purchase_requests WHERE request_number IS NOT NULL ORDER BY request_date DESC NULLS LAST LIMIT 1;`
   - `<REF>` and `<REF_SO>`: a customer PO ref and its sales order: `SELECT po_ref, so_number FROM sales_orders WHERE po_ref IS NOT NULL ORDER BY order_date DESC NULLS LAST LIMIT 1;`
   - `<BOTH>`: a number that is both a delivery order and a purchase order:
     `SELECT o.order_number FROM orders o JOIN purchase_orders p ON lower(p.po_number) = lower(o.order_number) LIMIT 1;`
     If none exists, write "none" and the owner skips step 9.
3. Two Chatbot Console contacts:
   - STAFF: linked to a staff user holding `sales_orders.outstanding` and `purchase_orders.placed`.
   - DEALER: a dealer contact with `sales_orders.outstanding`, linked to one customer (that customer id is used in step 2).
