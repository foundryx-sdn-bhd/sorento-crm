# Hand test: PR #1594 STOCK-DEBT-PROJECTION (rule D: pool supply counts for a project only through a link)

## URL

crew test copy

## Setup

Crew setup on the test copy of the lane head (rule D commit or later). The owner runs no
commands.

1. No migration and no data change. The copy uses the shared dev DB as it is: HQ is NOT a
   project reserve there (its `segment` is not `project`), so no reserve supply shows. The
   reserve half (HQ's unlinked 5,000 PO carried to Dec-Mar) is covered by
   `test_prod_srtwt2215_with_hq_a_project_reserve_carries_the_5000` and is hand-tested with
   PR #1597, which ships `HQ.segment = project`.
2. Read-only page: nothing in these steps writes or sends anything.

## Steps

1. Open the URL and sign in as a planner who can see Stock Debt.
2. In the sidebar, open Procurement, then Supply Chain, then Stock Debt.
3. Type SRTWT2215 in the search box.
4. Open Filters and set Book to Project. Leave "Projected balance" off.
5. Write down every month cell of the SRTWT2215 row.
6. Open Filters and turn "Projected balance" on.
7. Compare every month cell of the SRTWT2215 row with step 5.
8. Open Filters and set Book to All (keep "Projected balance" on).
9. Compare every month cell of the SRTWT2215 row with step 5 again.
10. Switch the projection off, find a SRTWT2215 month whose drill shows a BRW-BB line covered by the BRW SPO 333 (Covered by names the SPO), switch the projection back on and click that month's cell.
11. Read the grey projection line above the tabs, then that line's row in the Demand tab and its Covered by.
12. Close the drill. Type SRTWT7443 in the search box (Book All, "Projected balance" still on).
13. Compare each month cell with the same product under Book Project with the switch off.
14. Turn "Projected balance" off.

## Expected

1. Step 6: a "Projected balance" chip appears. Every month cell reads exactly what it read in step 5 (Book Project, switch off). Nothing grows by BRW's on hand, HQ's 5,000 PO or the BRW SPO 333: none of them counts beyond what a link places on a project line.
2. Step 9: for SRTWT2215, Book All with the switch on reads the same cells as step 5, although Book All with the switch off counts BRW's own on hand and orders in its months. (Each book's projection follows that book's own Covered by; for this row the two agree.)
3. Step 11: the projection line reads "Project bins N · Projected N", with N the cell's own figure. It names no pool, no dealer orders and no reserve supply. In the Demand tab, the line's Covered by names the SPO for the placed quantity only (not the whole 333), and its short quantity is what that leaves; the same figures as with the switch off.
4. Step 13: every SRTWT7443 cell equals its Book Project switch-off figure. Its unlinked open BRW POs and BRW SPO add nothing.
5. Step 14: the chip disappears and every cell reads the plain month view again (step 5 figures under Book Project; Book All's own figures under Book All).
