## Setup

1. No migration: the lane adds no column. The seed below is the only DB step; crew runs it on the
   shared dev DB before starting the copy (idempotent, additive: it writes a brand list only on
   two contacts whose list is NULL, and prints which two it chose). Undo later with
   `UPDATE respond_contacts SET brand_ids = NULL WHERE id IN ('<DUAL id>', '<MOCHA-ONLY id>')`.

```sql
-- BRAND-SCOPE-PER-COMPANY hand test seed. Idempotent; writes brand_ids only where NULL.
-- 1. Which brand rows the four Sorento brands resolve to (must print four rows).
SELECT b.id, b.brand_name
FROM brands b JOIN companies co ON co.id = b.company_id
WHERE co.code = 'SRT' AND upper(b.brand_name) IN ('SORENTO', 'CABANA', 'ELLECI', 'NO LOGO')
ORDER BY b.brand_name;

-- 2. DUAL = the oldest chatbot-allowed contact in BOTH SRT and MCH; MOCHA-ONLY = the oldest
--    chatbot-allowed contact in MCH and not in SRT. Both get the four Sorento brands.
WITH srt AS (SELECT id FROM companies WHERE code = 'SRT'),
     mch AS (SELECT id FROM companies WHERE code = 'MCH'),
     sorento_brands AS (
       SELECT array_agg(b.id ORDER BY b.brand_name) AS ids
       FROM brands b, srt
       WHERE b.company_id = srt.id AND upper(b.brand_name) IN ('SORENTO', 'CABANA', 'ELLECI', 'NO LOGO')
     ),
     dual AS (
       SELECT c.id FROM respond_contacts c
       WHERE c.chatbot_allowed
         AND EXISTS (SELECT 1 FROM respond_contact_companies m, srt WHERE m.respond_contact_id = c.id AND m.company_id = srt.id)
         AND EXISTS (SELECT 1 FROM respond_contact_companies m, mch WHERE m.respond_contact_id = c.id AND m.company_id = mch.id)
       ORDER BY c.created_at, c.id LIMIT 1
     ),
     mocha_only AS (
       SELECT c.id FROM respond_contacts c
       WHERE c.chatbot_allowed
         AND EXISTS (SELECT 1 FROM respond_contact_companies m, mch WHERE m.respond_contact_id = c.id AND m.company_id = mch.id)
         AND NOT EXISTS (SELECT 1 FROM respond_contact_companies m, srt WHERE m.respond_contact_id = c.id AND m.company_id = srt.id)
       ORDER BY c.created_at, c.id LIMIT 1
     )
UPDATE respond_contacts c
SET brand_ids = (SELECT ids FROM sorento_brands)
WHERE c.id IN (SELECT id FROM dual UNION SELECT id FROM mocha_only)
  AND c.brand_ids IS NULL
  AND (SELECT ids FROM sorento_brands) IS NOT NULL;

-- 3. Print the two contacts (same selection rule) with the list they now carry.
WITH srt AS (SELECT id FROM companies WHERE code = 'SRT'),
     mch AS (SELECT id FROM companies WHERE code = 'MCH'),
     dual AS (
       SELECT c.id FROM respond_contacts c
       WHERE c.chatbot_allowed
         AND EXISTS (SELECT 1 FROM respond_contact_companies m, srt WHERE m.respond_contact_id = c.id AND m.company_id = srt.id)
         AND EXISTS (SELECT 1 FROM respond_contact_companies m, mch WHERE m.respond_contact_id = c.id AND m.company_id = mch.id)
       ORDER BY c.created_at, c.id LIMIT 1
     ),
     mocha_only AS (
       SELECT c.id FROM respond_contacts c
       WHERE c.chatbot_allowed
         AND EXISTS (SELECT 1 FROM respond_contact_companies m, mch WHERE m.respond_contact_id = c.id AND m.company_id = mch.id)
         AND NOT EXISTS (SELECT 1 FROM respond_contact_companies m, srt WHERE m.respond_contact_id = c.id AND m.company_id = srt.id)
       ORDER BY c.created_at, c.id LIMIT 1
     )
SELECT 'DUAL' AS role, c.id, c.name, c.phone_number, c.brand_ids FROM respond_contacts c JOIN dual d ON d.id = c.id
UNION ALL
SELECT 'MOCHA-ONLY', c.id, c.name, c.phone_number, c.brand_ids FROM respond_contacts c JOIN mocha_only d ON d.id = c.id;

-- 4. One Mocha product code with stock, for step 1 of the hand test.
SELECT p.product_code, s.quantity_on_hand
FROM products p JOIN companies co ON co.id = p.company_id
JOIN stock s ON s.product_id = p.id
WHERE co.code = 'MCH' AND p.is_active AND s.quantity_on_hand > 0
ORDER BY p.product_code LIMIT 1;
```

2. DUAL and MOCHA-ONLY are the two contacts the seed's step 3 printed (name and phone). Both
   now carry SORENTO, CABANA, ELLECI, NO LOGO on the Brands card of their contact page.
3. Codes: MCH-CODE = the product the seed's step 4 printed. SRT-IN = SRTWB7108 (brand SORENTO).
   SRT-OUT = MAP5045C (brand MOCHA, a Sorento product). SRT-NULL = MWC7630-SH-S6 (Sorento product
   with no brand). Confirm each on Master Data > Products if the dev copy differs.
