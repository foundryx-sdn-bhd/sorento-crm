# Hand test #1712 (CONSIGN-PLAN)

## URL
crew test copy

## Setup

1. Sign in as Teh Jayson (the E2E admin account).
2. No migration and no data step. Nothing to run.
3. Consignment used: CG-202606-062 (dealer 300-J096, 3 lines at CON, partly returned). If it is not on the test copy, use any consignment whose Status reads `At customer` and whose agent is project class (ACT, ERIC NG or JENNIFER), and read its own line quantities in step 4.
4. A sales order for contrast: any open project sales order (Project Sales Admin > Sales Orders).

## Steps

1. From the sidebar open Project Sales Admin > Consignment.
2. Look at the toolbar, then open the Actions menu.
3. Tick CG-202606-062.
4. Open CG-202606-062 in a second tab (click its number) and note each line's Qty and Qty returned on the Lines tab. Close that tab.
5. Back on the list, click `Plan selected (1)`.
6. Read the board's line rows for CG-202606-062 and the summary buttons above the grid (Use own location / Borrow / Use BRW / Buy).
7. Tick every CG-202606-062 line, click `Decide`, pick `Borrow`.
8. Open the Location dropdown in the dialog.
9. Pick `CON`, type a reason (`goods at dealer`), click `Save 3 lines`.
10. Click `Confirm (3)`.
11. From the sidebar open Project Sales Admin > Consignment and open CG-202606-062.
12. Back on the Consignment list, tick CG-202606-062, open Actions, click `Reset planning (1)`, then `Reset planning` in the dialog.
13. From the sidebar open Project Sales Admin > Sales Orders, tick one open project sales order, click `Plan selected (1)`, tick a line, `Decide` > `Borrow`, open the Location dropdown. Close the dialog without saving.

## Expected

1. The Consignment list opens with a tick box on every row.
2. The toolbar shows `Plan selected (0)`, greyed out, with the hover reason `Tick the consignments to plan first.` The Actions menu holds exactly `Reset planning (0)` and `Refresh`. There is no Upload and no Add.
3. The button reads `Plan selected (1)`.
4. You have each line's Qty and Qty returned.
5. The fulfilment board opens with `?orders=CG-202606-062` in the address bar.
6. One row per line of CG-202606-062, each tagged `Consignment`. No row says `Outside fulfilment planning`. Each line's planned qty is its Qty minus its Qty returned. The summary shows Borrow suggested = the sum of those, Buy suggested 0.
7. A dialog titled `Decide 3 lines: Borrow` opens.
8. The Location list includes `CON`.
9. The dialog closes. The summary shows Borrow decided = the same total, Buy decided 0. The button reads `Confirm (3)`.
10. `1 of 1 orders confirmed` and `CG-202606-062: confirmed as revision 1 (0 purchase rows handed over)`.
11. The header reads `At customer`, `Consignment`, `Planned`, and a blue `Plan` button sits top right.
12. The dialog reads "... The consignment and its lines stay." with no upload checkbox. After Reset planning: a `Planning reset` toast. Open the consignment again: the chip reads `Not planned`.
13. The Location list for the sales order line does not include `CON`.
