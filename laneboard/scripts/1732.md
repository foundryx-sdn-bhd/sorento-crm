# Hand test #1732 (CONTACT-ACTIONS-COPY)

## URL
crew test copy

## Setup

1. Sign in as Teh Jayson (the E2E admin account).
2. No migration and no data step. Nothing to run. The copy never calls respond.io.
3. Pick (or set up by hand) one reference contact, "the source", whose contact page has:
   - Brands: two brands (for example Brava and Luxe)
   - Media access: Image on with a monthly limit (for example 30), Voice on with a monthly limit (60) and max clip (90 seconds)
   - Chatbot card: "Send files as links" ticked
   - Attachment types: at least one granted type
   - Portal forms: at least one override (for example Price tag request on)
   - Spec visibility: an override (for example hide Thickness)
4. Pick two other contacts, "the targets", that differ from the source on those settings. Write down each target's name, phone and linked customers.

## Steps

1. From the sidebar open Users & Access > People > Internal Users.
2. Tick the two targets.
3. Look at the bar above the grid, then open the Actions menu.
4. Close the menu, open it again and click `Disable messaging (2)`. Read the dialog, click Cancel.
5. Open Actions and click `Delete (2)`. Read the dialog, click Cancel.
6. Open Actions and click `Copy access from contact (2)`.
7. In "Copy access from", search the source by name and pick it. Read the summary list.
8. Click `Preview changes`. Expand each target row.
9. Click `Apply to 2 contacts`, then `Done`.
10. Open each target's contact page and read its Brands, Media access, Attachment types, Portal forms, Spec visibility and Chatbot sections.
11. Back on the list, tick one target, open Actions, `Copy access from contact (1)`, pick the source again, click `Preview changes`.

## Expected

- Step 3: the bar shows `2 selected`, one `Actions` button and `Clear`, and no other bulk buttons. The menu lists, in order: Export, Link customers (2), Enable messaging (2), Sync from Respond (2), Copy access from contact (2), Disable messaging (2), Delete (2). The last two are red.
- Step 4: the "Disable outbound messaging" dialog opens; Cancel leaves both contacts messageable.
- Step 5: the "Delete contacts" dialog opens; Cancel deletes nothing.
- Step 7: the summary has a line each for Access types, Tier, Chatbot switches (ends with "Send files as links on"), Regions, Field reveals, Agent access, Stock check mode, Locations, Companies, Market segments, Brands (the source's two brand names), Image access ("On, 30 a month"), Voice note access ("On, 60 a month, max 90s a clip"), Attachment types, Portal forms, Spec visibility. "Not copied" reads "Linked customers, CS routing, Memory".
- Step 8: each target shows its differences, including Brands, Image access, Voice note access, Send files as links, Attachment types, Portal forms and Spec visibility where they differed. A target with no brand scope shows "All brands" struck, then the source's brand names.
- Step 9: "Copy finished", 2 updated.
- Step 10: each target now matches the source on every one of those settings. Name, phone, linked customers, memory and language are unchanged from what you wrote down in Setup.
- Step 11: the target shows "No change" and "0 will change" (Apply is disabled).
