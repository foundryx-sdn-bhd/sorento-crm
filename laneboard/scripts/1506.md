# Hand test #1506 (ROGUE-CONVO-REVIEW PR-2: classes B, C, G, F)

## URL
crew test copy

## Setup

1. No migration and no seed: the lane adds no column and reads the catalogue as it is.
2. Sign in to the test copy and open the chatbot console. Pick a contact whose stock
   visibility is Availability only (a dealer; General Enquiries access is fine) with no open
   task or picker (send `cancel` first if one is open).
3. Have three catalogue facts from the dev DB (all codes below are examples; use what the
   SQL returns):
   - a 4-digit number that sits inside SEVERAL product codes:
     `SELECT product_code FROM products WHERE product_code ILIKE '%8066%' AND is_searchable IS NOT FALSE ORDER BY product_code;`
   - a 4-digit number that sits inside exactly ONE code (same query with another number);
   - a real code (e.g. `SRTSC07`) and a near-miss spelling of it that exists nowhere (`Srts07`).
4. The parser addenda are NOT in prod yet (class F is prompt-only): steps 9 and 10 below are
   graded on the dev v60 text with the two addendum files applied by hand, or skipped.

## Steps

1. Type the multi-code number followed by `stock ?` (e.g. `8066 stock ?`).
2. Reply `2`.
3. Reply `5`.
4. Type the single-code number followed by `x 3` (e.g. `9031 x 3`).
5. Type `stock?` on its own.
6. Type the near-miss spelling (e.g. `Srts07`).
7. Type a product-shaped word with no digit, e.g. `Srt-hp`.
8. Paste a whole catalogue line with the code inside it, e.g.
   `SORENTO ONE PIECE WASHDOWN TOILET (S-TRAP250MM)-SRTWC8354-SH`, then type `another 10`.
9. Send a photo of a product label with NO caption.
10. Send the same photo with the caption `X5`.

## Expected

1. A which-one picker headed `<NUMBER> matches N products. Which one?` listing exactly the
   codes the SQL returned, numbered from 1. Never `That would search every stock we have`
   and never `Couldn't find <NUMBER>`.
2. `How many units of <the second code>?`
3. That code's own availability line, one line (`<CODE> x 5: ✅ Got stock.` or its
   no-stock / ETA line), closed by `Please refer to your salesman.` where the dealer rule adds it.
4. `<the single code> x 3: ...` answered directly, no picker.
5. `That would search every stock we have - I need at least one filter to narrow it down.
   Give me a product code, warehouse, or date range, and I can look it up.` (unchanged control).
6. `Couldn't find SRTS07. Did you mean: 1. SRTSC07 ...` with quick replies (unchanged control).
7. `Here's what you want: Srt-hp` then `Couldn't find: "Srt-hp".` then `Please refer to your
   salesman.` The reply never reads `srt` on its own and lists nothing under the header.
8. No `• product: ...` line and no `(+N more)` line under the header. The miss quotes the
   pasted line exactly as typed (either `Here's what you want: <line> / Couldn't find:
   "<line>".` when the catalogue reads none of its words, or `Couldn't find: "<line>"
   (product).` when it does; once the v60 text carries the F(i) addendum and #1511 is live,
   SRTWC8354-SH is answered directly). `another 10` must NOT page a set of water closets.
9. The console trace (media_intake stage) shows no `null` and no `undefined` line above the
   codes; the reply is about the codes read.
10. The trace's rendered text starts with the line `X5`, then the codes.
