## Setup

1. No migration. The lane changes the MCP presenter (`sorento_crm_mcp/sorento_crm_mcp/presenters.py`),
   so the MCP server on the test copy must be restarted on this branch; the backend and the
   frontend are untouched.
2. Chatbot Console contact DEALER: a contact that holds the `Sales order outstanding` reveal
   (`sales_orders.outstanding`). Contact 900000008 holds it on the dev copy since the 13 Sep
   outstanding-report lane; any contact with that grant works.
3. Customer `<CUSTOMER>`: one with MORE THAN 20 products on outstanding delivery orders for
   DEALER's companies. On the dev copy (crew, 7 Oct 2026) 135 customers qualify; the largest
   are the masked labels C1e1dbd (365 products), C41795c (281) and C4ffc6a (249). Read-only SQL
   to pick one (the route's own population, outstanding_report_service.py `_fill_do`):

   ```sql
   SELECT c.customer_name, COUNT(DISTINCT l.product_id) AS products
   FROM orders o
   JOIN order_lines l ON l.order_id = o.id
   JOIN products p ON p.id = l.product_id
   LEFT JOIN customers c ON c.id = o.customer_id
   WHERE o.deleted_at IS NULL
     AND (o.order_status_id IS NULL
          OR o.order_status_id NOT IN (SELECT id FROM order_statuses WHERE lower(status_code) IN ('delivered', 'completed'))
          OR o.actual_delivery_date IS NULL)
   GROUP BY c.customer_name
   HAVING COUNT(DISTINCT l.product_id) BETWEEN 21 AND 60
   ORDER BY products DESC
   LIMIT 10;
   ```
